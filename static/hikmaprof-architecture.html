HikmaProf

AI-Powered Document → Presentation → Video Pipeline

TypeScript / Node.js — Claude AI calls & PPTX generation
Python / Flask — Web server, TTS, video composition
Step 1
User Uploads Document
PDF / DOCX / LaTeX file — with choices for template style, color scheme, language (11 supported), number of slides (5–30), and optional Hikma avatar character.
Python · Flask /api/generate
Step 2 · TypeScript
Claude AI Reads & Plans the Presentation
Document text is sent to Claude claude-sonnet-4-20250514. Claude returns a structured Slide Plan: slide titles, bullet points, speaker notes, layout type, theme colors — one entry per slide.
Claude AI · SlidePlan JSON
Step 3 · Optional
User Reviews & Edits the Slide Plan
If preview mode is on, the pipeline pauses and shows the AI-generated slide cards. The user can edit titles, bullets, or reorder slides before approving to continue.
Optional · awaiting_approval state
Step 4 · TypeScript
PPTX is Built, Validated & Auto-Fixed
The slide plan is rendered into a .pptx file using the chosen template. Claude Vision then checks each slide for layout issues, text overflow, and contrast problems. If issues are found, Claude auto-fixes them — up to 5 iterations. Speaker notes become the transcript.txt.
PptxGenJS · Visual Validator · Auto Fixer
Step 5 · Python
Slides Rendered to Images
PPTX → PDF (LibreOffice or PowerPoint COM) → high-resolution PNG images, one per slide. These become the video frames.
PyMuPDF · LibreOffice · pdftoppm
Step 6 · Python
Voice Narration Generated (TTS)
Each slide's transcript text is converted to speech using Microsoft Edge Neural TTS — gender-matched to the chosen avatar character. Falls back to Google TTS if Edge TTS fails. One audio file per slide.
Edge TTS → gTTS → silent fallback
Step 7 · Python
Final Video Composed
Each slide is composed as a layered video clip:

█ Slide image — full background frame
● Drop shadow — blurred dark ellipse beneath avatar
▬ Dark panel — semi-transparent navy rounded rectangle
● Avatar circle — pre-built video, muted & looped, white border ring, 0.4s fade-in

All per-slide clips are concatenated into one final MP4.
MoviePy · PIL · FFmpeg
